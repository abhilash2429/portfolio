# abhilash24.me

Personal site and blog of Abhilash Reddy Manda, built with Next.js, Velite and Tailwind.

## Requirements

- Node.js 20+
- npm 10+

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Quality

```bash
npm run lint
npm run format
```
